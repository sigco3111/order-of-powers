# QA Q1: 실플레이 점검

## 플레이한 것
- 라이브 https://sigco3111.github.io/order-of-powers/ 에서 일반 게임(튜토리얼·debug 아님): 유럽연합, 8라운드, AI 보통 3명.
- 라운드 1~3은 390x690 iframe, 4~8은 1280x690 iframe. 라운드 4 시작에서 새로고침 → `이어하기`로 같은 라운드 4에서 재개됨.
- 실제 클릭만 사용(자산 선택·카드 선택/계획에 넣기·지역 선택·계획 확정·해결 시작·정산·상점 구매·사건 시트)으로 결과 화면까지 완주.
- 결과: 미국 승, 나는 4위(20점). 결과 화면 합계(지역 16 + 위신 4 + 비밀 목표 0)와 8라운드 정산 누계(16)가 맞음. `oop-records-v1`에 기록 저장 확인.
- 보드 머리띠의 `규칙`·`설정`은 모바일/데스크톱 모두 열리고 닫힘. 콘솔 오류 0건, 화면에 'undefined'/'null' 없음.

## 발견
1. 상점 구매 안내가 "복지 확대을(를) 구매했습니다"로 조사가 섞임. (수정함)
2. 해결 단계에서 AI 3명의 연출이 약 8초 걸림(>4초). `연출 건너뛰기`가 있어 막히지는 않음.
3. 카드를 계획에 넣기까지 2번 클릭(카드 → 계획에 넣기). 지역이 필요한 카드는 해결 때 한 번 더 고름(총 4번).
4. 모바일에서 지역 선택 칩이 가로 스크롤이라 중동 이후는 화면 밖(스크롤해야 보임). 지도 점선 지역을 눌러도 됨.
5. 지역이 안 정해진 카드도 `계획 확정`이 눌림(해결 때 선택 창이 뜸).
6. 보드의 세력 '점수'는 지역 점수만이고 결과 화면 '합계'는 위신·비밀 목표를 더해 숫자가 달라 보임(16 → 20).
7. 모바일 지도 라벨(북미/남미)이 지도 위에서 겹쳐 보임(스크린샷 1장으로만 확인).

## 열린 문제
- 위 2~7번은 설계 판단이 필요하거나 화면 확인이 더 필요해 고치지 않음.
- 예산 제한으로 스크린샷을 적게 써서 글자 잘림은 충분히 검사하지 못함(특히 결과 화면·상점 모바일).
