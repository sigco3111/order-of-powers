# UI 아트 디렉션 — "정세 브리핑"

Order of Powers의 화면은 **인쇄된 정세 보고서**이자 **탁상 보드게임**처럼 보여야 한다. 웹 서비스 대시보드처럼 보이면 실패다. 이 문서의 규칙은 `src/ui/tokens.css`, `src/ui/components.css`에 그대로 구현되어 있고, 모든 화면은 이 토큰만 쓴다.

## 1. 핵심 규칙
1. **종이 위의 인쇄물**: 바탕은 따뜻한 종이색 `#E9E2D0` + 아주 옅은 SVG 노이즈 결. 글자와 2px 테두리는 잉크색 `#1B2230`.
2. **각진 모서리**: 둥근 정도는 최대 3px. 알약 모양·큰 둥근 카드 금지.
3. **딱딱한 그림자**: 흐림 없는 오프셋 그림자(`4px 4px 0`, 잉크 28%)만 쓴다. 번지는 그림자·글로우 금지.
4. **고무 도장**: 상태(비공개, 선택됨, 승리 등)는 붉은/잉크색 이중 테두리 도장으로 표시. 약 -2도 기울임, `mix-blend-mode: multiply`.
5. **자료는 점선 리더 + 모노 숫자**: `항목 ········ 12`. 숫자는 항상 IBM Plex Mono(자리 맞춤).
6. **비대칭 문서 레이아웃**: 왼쪽 좁은 "사건 철(case file)" 레일 + 본문. 가운데 정렬 히어로 금지. 문서 머리띠 `문서 번호 OP-0001 · 대외비`는 화면 맨 위에 한 줄만(남발 금지).
7. **계층은 크기로**: 라운드·점수는 아주 큰 모노 숫자(`--fs-numeral`), 라벨은 작은 대문자풍 + 자간 .08em.
8. **움직임은 짧고 끊어서**: 120~200ms, `steps()`. 확정은 "도장 찍기"(1.15배 → 1배). 바운스·스프링 금지. `prefers-reduced-motion`과 설정의 "모션 줄이기"를 따른다.

## 3. 토큰 (`src/ui/tokens.css`)
| 구분 | 이름 | 값 | 용도 |
| --- | --- | --- | --- |
| 종이 | `--paper` / `--paper-dark` / `--paper-light` | #E9E2D0 / #D8CFB8 / #F1ECDD | 바탕 / 머리띠·눌린 면 / 패널 |
| 잉크 | `--ink` / `--ink-soft` | #1B2230 / #4A5263 | 글자·테두리 / 보조 글자 |
| 강조 | `--brass` / `--brass-text` / `--stamp` | #B08D3C / #6F5514 / #A8362A | 위신·점수 면 / 놋쇠색 글자 / 경고 도장 |
| 세력 | `--f-atlas` `--f-redDragon` `--f-polarStar` `--f-emerald` | #2F4B7C #A63A2B #3E7C86 #4C7A4A | 모서리 띠·칩·문양 (작은 글자색 금지) |
| 카드 분류 | `--c-domestic` `--c-diplomacy` `--c-military` `--c-economy` | #7A6A3A #3E6A8A #8A3A32 #5A7A4A | 내정 / 외교 / 군사 / 경제 |
| 글꼴 | `--font-display` `--font-body` `--font-mono` | Nanum Myeongjo 800 / Noto Sans KR 400·500·700 / IBM Plex Mono | 제목 / 본문 / 숫자·라벨 |
| 선 | `--line` `--hair` `--radius` | 2px / 1px / 3px | 테두리 |
| 그림자 | `--shadow` `--shadow-sm` | 4px 4px 0 / 2px 2px 0 (잉크 28%) | 패널·버튼·칩 |
| 시간 | `--t-fast` `--t-mid` `--t-slow` | 120 / 160 / 200ms, `steps()` | 전환 |
| 간격 | `--s1`~`--s8` | 4 · 8 · 12 · 16 · 24 · 32 · 48 · 72px | 여백 |

색 대비(AA): 잉크/종이 약 12:1, 보조 잉크/종이 약 6:1, 도장 붉은색/종이 약 5:1. 놋쇠(`--brass`)와 세력색은 글자 대비가 부족하므로 **면·테두리·문양에만** 쓰고, 그 위 글자는 잉크 또는 밝은 종이색을 쓴다(놋쇠색 글자가 필요하면 `--brass-text`). 색만으로 구분하지 않는다: 세력은 색 + 엠블럼 + 이름, 카드 분류는 색 + 태그 글자.

## 4. 부품 (`tokens.css` · `components.css`)
| 부품 | 클래스 | 설명 |
| --- | --- | --- |
| 카드 | `.card` `.card--{domestic,diplomacy,military,economy}` | 모서리를 깎은(clip-path) 2px 잉크 테두리 프레임, 상단 분류색 띠 + 비용(모노), 아이콘 칸, 점선 아래 본문 |
| 토큰 | `.chip` `.chip--{faction}` `.chip--brass` | 마분지에서 도려낸 네모 말. 세력색 면 + 안쪽 홈선 + 모노 숫자. 영향력·점수 표시 |
| 스탬프 | `.stamp` `.stamp--ink` `.stamp--brass` `.stamp--press` | 이중 테두리 도장. `--press`는 도장 찍기 연출 |
| 패널 | `.panel` `.panel__head` `.panel__body` | 종이 밝은 면 + 2px 테두리 + 딱딱한 그림자, 머리띠는 종이 어두운 면 |
| 버튼 | `.btn` `.btn--primary` `.btn--sm` `.btn--block` | 기본 = 윤곽선, 주요 = 잉크 면 + 종이색 글자 + 그림자. 눌림 = 3px 이동. 비활성 = 점선 테두리. 높이 최소 48px |
| 내비 | `.rail` `.steps` (src/ui/screens.css) | 데스크톱은 왼쪽 사건 철 레일, 모바일은 상단 3단계 괘선 띠 |
| 기타 | `.tag` `.rule` `.leader` `.res-row` `.sheet` `.check` `.icon` | 분류 태그, 괘선, 점선 리더, 자원 행, 모달 시트, 네모 체크, 마스크 아이콘 |

아이콘은 `assets/` 의 CC0 PNG를 `.icon` 마스크로 쓴다(색은 `currentColor`). 자본 `kenney-game-icons/coin`, 위신 `kenney-game-icons/star`, 에너지 `kenney-board-game-icons/fire`, 산업 `kenney-board-game-icons/resource_iron`, 카드 `kenney-board-game-icons/cards_fan`. 세력 엠블럼 4종은 직접 그린 `assets/ui/emblem-<세력>.svg` (아틀라스: 동심원 + 북쪽 눈금, 적룡: 사각 안 뱀 곡선, 북극성: 원 안 8갈래 별, 에메랄드: 쌓인 잎·마름모 화살표).

## 5. 화면 목록
| 화면 | 상태 | 내용 |
| --- | --- | --- |
| 타이틀 | U1 | 큰 명조 제목, 비공개 시뮬레이션 도장, 새 게임/이어하기/규칙/설정, 오른쪽 옅은 세계 지도 |
| 세력 선택 | U1 (setup) | 세력 서류 4장, 라운드 6/8/10, AI 난이도, 시드(고급), 작전 개시 |
| 규칙 설정 | U1 (setup에 포함) | 라운드·난이도·시드. 이후 세부 규칙 추가 시 분리 |
| 보드 | U2 | 세계 지도 + 영향력 칩, 위쪽에 라운드·점수 큰 숫자, 왼쪽 레일에 자원 |
| 손패 | U2 | 아래쪽 카드 줄(가로 스크롤), 선택 시 들어 올림, 계획 칸 3개 |
| 시장 | U3 | 시장 카드 슬롯 + 구매 시트 |
| 이벤트 | U3 | 라운드 시작 전보(전보 용지 모양 패널 + 도장) |
| 결과 | U4 | 순위표(점선 리더), 승자 도장, 지역별 점수 |
| 튜토리얼 | U4 | 단계별 말풍선 대신 "주석 메모" 패널 |
| 설정 | U1 (시트) | 모션 줄이기, 효과음. 이후 확장 |

세력 서류의 약점 줄은 기획서에 명시된 값이 아니라 다른 세력의 강점에서 역으로 도출한 임시 문구다(밸런스 확정 시 갱신). 서류 위의 폴더 탭(`파일 0N · 세력`)은 선택되면 잉크색으로 채워진다.

## 6. 모바일 우선 배치
- 기준은 **360px 세로**. 한 열, 좌우 여백 16px, 최소 터치 영역 44px(버튼은 48px).
- 문서 머리띠는 맨 위 한 줄. 왼쪽 레일은 상단 3단계 괘선 띠(`01 표지 · 02 편성 · 03 작전`)로 접힌다.
- 세력 서류는 한 줄에 한 장(왼쪽 8px 세력색 띠), 선택 시 굵은 테두리 + 그림자 + "지정" 도장. 주요 버튼은 화면 아래 고정 띠로 둬 엄지가 닿게 한다.
- **태블릿**(≥ 600px): 세력 서류 2열.
- **데스크톱**(≥ 900px): 2열. 왼쪽 220px 사건 철 레일(문서 번호, 단계, 저장 상태)과 본문; 본문은 서류 2×2 + 오른쪽 작전 설정 패널. 모달 시트는 가운데 상자로 바뀐다.
- 글자는 모두 선택 가능, `word-break: keep-all`. 포커스는 2px 잉크 윤곽선 + 2px 간격.

## 7. 브라우저 빌드와 엔진
`src/engine`은 Node 전용 API를 쓰지 않는다. 단, `node-data.js`만 `node:fs`로 JSON을 읽으므로 브라우저에서는 쓰지 않고 `src/engine/browser-data.js`(`fetch`로 `src/data/*.json`을 읽어 `setData`로 등록)를 쓴다. 두 파일은 같은 모양의 data 묶음을 돌려준다. 진입점은 저장소 루트 `index.html` → `src/ui/app.js`. 저장 키는 `oop-save-v1`.
