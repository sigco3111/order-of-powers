# Order of Powers (권력의 질서) — 게임 기획서

> 버전 0.4 · 상태: 기획 · 작성: 2026-11-06

## 1. 한 줄 소개
네 강대국 중 하나의 지도자가 되어, 8라운드(6·8·10 중 선택) 동안 내정·외교·군사 카드를 모아 덱을 키우고 세계 8개 지역의 영향력을 겨루는 **웹 전략 보드게임**.

## 2. 기획 의도
- 실제 보드게임 "월드오더"처럼 *덱 빌딩 + 지역 장악*의 긴장감을 웹에서 가볍게 즐기게 한다.
- 원작의 규칙·카드 문구·그림을 쓰지 않고, **가상의 세력과 자체 규칙**으로 만든 독자 작품으로 한다.
- 한 판 15~40분 (라운드 수에 따라 6라운드 약 20분, 8라운드 약 28분, 10라운드 약 35분), 혼자서 AI 3명과 즐기는 것에서 시작하고, 이후 온라인 대전으로 확장한다.
- 모바일 세로 화면에서도 할 수 있는 카드 중심 UI.

## 3. 목표 사용자
- 보드게임과 전략 게임을 좋아하는 20~40대, 짧게 여러 판 하고 싶은 사람
- 규칙서 읽기가 부담스러운 입문자 (튜토리얼 제공)

## 4. 세계관과 세력 (가상)
시대는 "균열 이후"의 근미래. 낡은 질서가 흔들리고 네 강대국이 새 질서를 두고 겨룬다.

| 세력 | 컨셉 | 고유 강점 |
| --- | --- | --- |
| 아틀라스 연합 | 해양 동맹과 금융 | 외교 카드 효율, 동맹 보너스 |
| 적룡 공화국 | 제조업과 인프라 | 내정 카드 효율, 자원 생산 |
| 북극성 연방 | 에너지와 군사 | 군사 카드 효율, 기지 건설 |
| 에메랄드 연맹 | 규범과 연합 | 영향력 방어, 제재와 조약 |

## 5. 핵심 게임 루프
1. **라운드 시작**: 이벤트 카드 1장 공개 (전 세계에 영향).
2. **계획**: 손패 5장 중 3장을 골라 비공개로 배치.
3. **공개와 실행**: 모두 동시에 공개, 우선권 순서대로 효과 실행.
4. **정산**: 지역별 영향력 비교로 점수 계산, 자원 수입.
5. **성장**: 상점에서 카드 구매(덱 빌딩), 사용한 카드 정리.
6. 마지막 라운드 종료 후 최종 점수 집계.

라운드 수는 시작할 때 6(짧게) · 8(보통, 기본) · 10(길게) 중에서 고르며, 이벤트 덱과 상점 카드 수, 수입 곡선은 선택한 라운드 수에 맞춰 자동 조정된다. 라운드가 많을수록 후반에 덱이 더 두꺼워지고 역전 기회가 커진다.

## 6. 카드와 자원
- 카드 3계열: **내정**(경제·기술·안정), **외교**(조약·동맹·여론), **군사**(기지·억지력·개입).
- 자원: 💰 자본, 🛢 에너지, 🏭 산업, ⭐ 위신(점수와 연결).
- 시작 덱은 세력마다 다른 12장 (튜토리얼은 공용 10장). 라운드마다 상점에서 새 카드 1~2장 구매.
- **전략 자산**: 한 판에 한 번만 쓰는 강력한 특수 카드 (시작 때 2장 중 1장 선택).
- **성장 카드**: 구매하면 게임 끝까지 영구 효과를 주는 내정 카드 (덱에 들어가지 않음).
- 카드 한 장은 이름, 계열, 비용, 효과 한 줄, 아이콘으로 구성. 효과 문구는 전부 자체 작성.

## 7. 세계 지도 (8개 지역)
북아메리카 · 남아메리카 · 유럽 · 러시아·중앙아시아 · 중동·북아프리카 · 사하라 이남 아프리카 · 동아시아 · 남아시아·동남아·오세아니아.
- 각 지역에는 **영향력 칸**(최대 6)과 **특성**(자원 산출, 점수 가치)이 있다.
- 영향력은 세력 토큰으로 표시, 가장 많은 세력이 지역을 **주도**하며 라운드 정산 때 점수를 받는다.
- 군사 카드로 **기지**를 세우면 영향력 +1과 방어 보너스. 외교 카드로 **조약**을 맺으면 두 세력이 같은 지역에 공존.
- 지도는 코드로 그린 단순한 SVG 형태(실제 국경선 사용 안 함).

## 8. 승리 조건
마지막 라운드 종료 시 점수 합계가 가장 높은 세력. 점수 = 주도한 지역 점수 + 위신 + 조약/기지 보너스 + 비밀 목표 카드.
- **비밀 목표 카드**: 게임 시작 때 2장 받음 (예: "세 개 지역 이상에 기지를 둔다").

## 9. 모드
- **싱글**: 나 + AI 3명 (난이도: 쉬움 / 보통 / 어려움)
- **라운드 수 선택**: 짧게 6 · 보통 8(기본) · 길게 10. 일일 도전은 기본 8라운드로 고정.
- **튜토리얼**: 2라운드 축소판
- **일일 도전**: 매일 같은 시드의 시나리오 (기록 비교, 후속)
- **온라인 대전**: 친구와 방 코드로 대전 (후속)
- **다회차 요소(후속)**: 판이 끝날 때 얻는 경험치로 세력별 시작 카드·칭호 해금.

## 10. AI 설계
- 규칙 기반 휴리스틱: 카드 가치 점수화 + 지역별 위협도·기회 평가.
- AI 밸런스 시뮬레이션은 6/8/10라운드 각각에서 세력별 승률을 맞춘다.
- 난이도는 평가 가중치와 무작위성, 숨은 정보 추측 정확도로 조절.
- 모든 AI 결정은 시드 기반이라 재현 가능 (디버그와 일일 도전에 활용).

## 11. UI/UX
- 화면: 타이틀 → 세력 선택 → 게임판(지도 + 손패 + 상단 자원바) → 정산 화면 → 결과.
- 카드는 드래그 또는 탭으로 배치, 효과는 한 줄 툴팁, 지역은 탭하면 상세 패널.
- 한국어 UI, 큰 글씨, 색약을 고려해 세력을 색 + 문양으로 구분.
- 사운드: 카드 뒤집기, 주사위/토큰 소리, 정산 효과음, 잔잔한 배경음.

## 12. 기술 설계
- HTML / CSS / JavaScript (ES 모듈), 번들러 없이 시작, 정적 호스팅 (GitHub Pages).
- 지도와 카드는 SVG + DOM, 애니메이션은 CSS/Web Animations.
- 게임 상태는 순수 데이터 + 순수 함수(리듀서)로 만들어 AI 시뮬레이션과 테스트가 쉽게 한다.
- 저장: localStorage (진행 중 게임, 설정, 기록).
- 폴더: `src/engine`(규칙), `src/ai`, `src/ui`, `src/data`(카드·지역 JSON), `assets/`, `docs/`.
- 후속 온라인 대전: 서버리스 방식(예: WebRTC 또는 Firebase)을 검토.

## 13. 에셋 계획
- 이미 보유한 CC0 에셋(UI 키트, 아이콘, 효과음, 음악)을 `assets/`에 모은다 (`docs/ASSETS.md` 참고).
- 직접 만들 것: 세력 문장(SVG), 지도 지역(SVG), 카드 일러스트(아이콘 조합).
- 폰트: Noto Sans KR, Black Han Sans (Google Fonts).

## 15. 위험과 대응
- **원작과의 유사성**: 이름, 세력, 규칙 문구, 그림을 모두 독자적으로 만든다. 공개 전 점검한다.
- **밸런스**: AI끼리 수천 판 시뮬레이션으로 세력별 승률을 맞춘다.
- **라운드 수별 밸런스**: 6/8/10 각각에서 수입 곡선과 카드 구매 비용을 따로 조정한다.
- **범위 과다**: M2까지를 MVP로 정하고 온라인은 후속으로 미룬다.
