# U3b 상태: 상점과 결과 화면

## 새로 된 것
- 상점: 보유 자본, 내 덱 요약, 시장/첫 구매/성장 카드, 가격(원가 취소선)과 `자본 부족 (−N)` 사유, 구매 완료 도장, 상대 구매 목록, `상점 마치기`. 마지막 라운드에는 상점이 없다(엔진 규칙).
- 결과: 최종 보고서(점수표·동점 처리 문구·목표 달성·점수 추이 그래프·하이라이트·설정), 다시 하기/설정으로/기록 공유/기록 보기/보드 보기.
- 기록과 업적: 최근 20판(`oop-records-v1`), 누적(`oop-meta-v1`), 업적 5종. 타이틀의 `05 기록`에서 본다.
- 모바일 계획 트레이: 접이식 독(슬롯 3칸과 `계획 확정`만 보이고, `손패`를 누르면 펼침). 접힌 상태에서 지도가 화면 높이의 절반 이상.
- 테스트: `tests/ui-shop.test.js` 12개. `node --test` 전체 119개 중 118 통과, 1 건너뜀.

## 알려진 한계
- 카드 상세 시트에 카드 문구가 두 번 나온다 (card.js 기존 동작).
- 기록 공유는 클립보드를 쓸 수 없으면 텍스트 상자로 대신한다.
