# QA M6: 계획 단계로 옮긴 두 번째 질문

해결 때 사람 카드가 다시 묻던 질문을 계획 선택판(1/3단계 …)으로 옮겼다. 선택은 계획 확정 때 `ui.pre`(저장 `oop-save-v1`)에 들어가 새로고침 뒤에도 유지된다. 코드: `src/ui/plan-model.js`(`planSteps`), `src/ui/play.js`. 테스트: `tests/ui-m6-plan.test.js`(7개), `tests/ui-f1-plan.test.js` 갱신. `tests/ui-*.test.js` 80개 통과.

## 해결 때 두 번째 질문을 하던 카드 (cards.json의 효과 정의를 훑어 찾음)
| 카드 | 예전에 해결 때 묻던 것 | 이제 계획에서 |
| --- | --- | --- |
| 국제기구 결의(dip-09), 제한 개입(mil-09), 기동 타격(mil-10), 전략 폭격기(mil-12) | 지역 뒤 영향력을 줄일 세력 (고른 지역에 상대가 둘 이상일 때). 전략 폭격기는 지역 자체도 해결 때 물었다 | 지역 → 피해 세력 |
| 특수 작전(mil-14) | 세력 뒤 기지를 부술 지역 (기지가 두 곳 이상일 때) | 세력 → 기지 지역 |
| 원조 패키지(dip-03) | 💰 2 추가 지불 예/아니오 | 예/아니오 → (예일 때만) 지역 |
| 비상 대책(neu-01) | 버릴 손패 | 버릴 카드 (계획에 넣은 다른 카드는 후보에서 제외) |
| 위기 관리(dom-15) | 사건으로 잃은 영향력 중 무시할 지역 (내 손실 지역이 둘 이상일 때) | 무시할 지역 |

이미 계획에서 묻던 것(지역, 다자 회의 지역 두 곳, 조약·자원 빼앗기·손패 확인·버리게 하기·기지 파괴·계획 공개의 대상 세력)은 그대로다.

## 해결 때 묻는 경우 (모두 짧은 안내 문구가 먼저 뜬다)
- 계획 때 고른 값이 해결 때 고를 수 없게 됨 → "계획 때 고른 ○○은(는) 이제 고를 수 없어요. 다시 고르세요."
- 계획 때 없던 질문이 생김(예: 앞 카드 효과로 상대가 늘어남) → "계획 뒤 상황이 바뀌어, 계획 때 없던 질문이 생겼어요."
- **정보전(neu-02)의 버리게 할 카드**: 확인한 손패 2장을 본 뒤에야 고를 수 있어서 계획 때 정할 수 없다. 의도된 예외이며 안내 문구에 이유가 나온다.

## 이번에 손대지 않은 것
- 전략 자산 사용과 사건·성장 카드(`ignoreEventEffectInRegionPerRound`)로 생기는 선택은 카드가 아니라서 그대로 그 자리에서 묻는다.
- 라이브 클릭 확인은 하지 못했다. 선택판 화면은 DOM 없이 모델과 저장·재개 경로(테스트)로만 검증했고, 눈으로 본 확인은 남아 있다.
- 튜토리얼은 외교 서한(지역 하나)만 쓰므로 바꾸지 않았다.
