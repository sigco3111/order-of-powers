# 국가 20개 (G20)

플레이어가 고를 수 있는 국가. 데이터는 `src/data/countries.json`, 엔진 해석은 `src/engine/countries.js`.

- 한 판은 언제나 네 자리(외교형·산업형·군사형·성장형). 고른 국가의 원형 자리에 앉고, 나머지 세 자리는 다른 원형의 국가가 시드로 무작위 배정된다 (고급 설정에서 직접 선택).
- 국가는 **본거지 지역**과 **특성 하나**를 더한다. 규칙·덱·카드·원형 밸런스는 그대로다.
- 본거지는 시작 영향력을 주지 않는다 (`HOME_START = 0`). 시작 영향력 1을 주면 지역 점수를 먼저 쌓는 쪽이 이겨 균형이 무너졌다 ([BALANCE_REPORT.md](BALANCE_REPORT.md) "국가 도입 후"). 본거지는 특성(본거지 첫 영향력 +1)과 화면 표시에 쓰인다.
- 소개 문장은 지리·경제 특징만 적었다. 색은 지도·말에는 원형 색을 쓰고, 국가 강조색은 자료철 카드 모서리에만 쓴다.

## 어색한 배정

- **멕시코(산업형)**: 본거지 북아메리카 — 미국(군사형)·캐나다(외교형)와 같은 지역이다. 산업형 덱은 동아시아 쪽 제조 국가에 어울려 지역 산출(자본)과 덱 성격이 어긋난다.
- **이탈리아(산업형)**: 유럽이 본거지라 외교형(유럽연합·프랑스·독일·영국)과 지역이 겹친다.
- **호주(군사형)**: 본거지가 남아시아·동남아·오세아니아 하나로 묶여 있어 인도·인도네시아(성장형)와 겹친다.
- **튀르키예(군사형)·사우디아라비아(군사형)**: 중동·북아프리카 한 지역에 같이 있을 수 있다 (같은 원형이라 한 판에는 한 자리뿐이므로 충돌은 없다).
- **남아프리카공화국(성장형)**: 지역 "사하라 이남 아프리카" 전체가 본거지로 표시된다. 지역 단위가 넓다.
- **유럽연합**: 국가가 아니라 공동체다. G20 구성원이라 포함했고 "국가" 자리에 앉는다.
