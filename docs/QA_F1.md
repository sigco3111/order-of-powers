# QA F1: 마무리 점검

테스트: `node --test` 통과 (새 파일 `tests/ui-f1-plan.test.js` 4개). 점검은 라이브 https://sigco3111.github.io/order-of-powers/ 를 390x690 iframe에서 실제 클릭으로 했다.

## 1. 계획 때 고른 선택을 저장
- 계획 확정 때 고른 지역·지역 두 곳·대상 세력을 `oop-save-v1`의 `ui.pre`(라운드, 카드별 목록)에 넣는다. 새로고침 뒤에도 해결 때 묻지 않고, 쓴 값은 저장에서 빠진다.
- 지역 두 곳 카드(다자 회의류)와 대상 세력 카드(조약·자원 빼앗기·손패 확인·버리게 하기·기지 파괴·계획 공개)는 카드를 누르면 선택판이 단계별로(1/2단계 …) 열린다. 이전 단계·취소 가능. (`src/ui/plan-model.js`, `src/ui/play.js`)
- 후보가 한 곳뿐이면 엔진이 묻지 않으므로 단계도 없다. 해결 때 후보가 사라지면 예전처럼 직접 묻는다.

## 2. 튜토리얼 14단계 (라이브, 실제 클릭)
- 1~14단계 모두 막힘 없이 통과(카드 → 지역 칩 → 계획 확정 → 해결 시작 → 정산 → 구매 → 끝).
- 고침: 안내 상자에 글자 "null"이 찍혔다(`replaceChildren(null)`). 마지막 단계의 `정식 게임 시작`은 코드상 `finish('setup')`(8라운드·보통 미리 선택); 라이브 클릭은 탭 이동으로 끊겨 화면 확인 못 함.

## 3. 접근성
- 대비(계산): 잉크/종이 12.3, 흐린 글자/종이 6.1(종이 어두운 면 5.1), 놋쇠 글자 5.4. 도장 붉은색 #A8362A는 어두운 종이 위 4.2였다 → #9A3025(4.8)로 변경.
- 모든 버튼에 `:focus-visible` 2px 잉크 윤곽선(전역). 라이브 Tab 확인: 선택판·손패·설명 순서, 이름 없는 버튼 0개.
- 글자 130% + 고대비, 390px: 보드 머리글·계획 칸 가로 넘침 없음. 전략 자산 버튼 글자가 잘려 줄바꿈으로 고침.
- `prefers-reduced-motion`과 설정 '움직임 줄이기' 모두 CSS에 있음(코드 확인).

## 남은 문제
- 카드 두 군데에서 묻는 효과(지역 뒤 피해 세력 선택, 기지 지역 선택)는 여전히 해결 때 묻는다.
- 키보드 Tab은 보드에서 몇 개만 확인했다(전체 감사 아님).
