# QA Q2: 조작과 모바일 정리

Q1에서 나온 열린 문제 2~7번을 고쳤다. 테스트: `node --test` 165 통과(새 테스트 11개).

## 고친 것
1. 지역을 정하지 않은 카드가 계획에 있으면 `계획 확정`이 꺼지고 버튼 아래에 "지역을 정하지 않은 카드가 있어요"가 뜬다. 계획 칸의 '지역 선택 필요' 태그는 그때만 나온다. (`src/ui/plan-model.js`, `tests/ui-q2-plan.test.js`)
2. 세력 줄 점수를 "지역 16 · 위신 4 · 합계 20"으로 표시. 모바일은 합계만 보이고 탭하면 내역이 펼쳐진다. 게임 중에는 비밀 목표가 빠진다고 안내(비밀 목표 별도), 종료 뒤에는 결과 화면과 같은 엔진 합계(`finalScores`)를 쓴다. (`src/ui/score-view.js`, `tests/ui-q2-score.test.js`)
3. 지역 선택 칩을 가로 스크롤 대신 격자로 감쌌다(한 줄 4칸, 8개가 두 줄).
4. 지도 라벨: 북미는 위쪽, 남미는 왼쪽 아래 바다로 시작 위치를 보정(`LABEL_NUDGE`), 모바일 확대 버튼은 가로 한 줄로 바꾸고 라벨이 버튼 아래로 들어가지 않게 했다.
5. 카드 한 번 누르면 첫 빈 칸에 들어간다. 지역이 필요한 카드는 손패 자리에 지역 칩이 뜨고 칩을 누르면 칸이 채워진다(2번). 지도의 점선 지역을 눌러도 된다. 계획 칸에 `빼기` 버튼, Esc로 취소. 설명은 카드 아래 `설명` 버튼. 해결 단계에서는 계획 때 고른 지역이 자동으로 적용된다(고를 수 없게 되면 예전처럼 물음). 디버그 자동 계획은 그대로. 튜토리얼 6·7·9단계 문구와 목표를 새 조작에 맞췄다.
6. AI 연출: 행동당 250ms(보드가 안 바뀌면 절반), AI 몫은 라운드당 4초 상한, 빠른 진행은 절반. 내 행동 연출(700ms)과 `연출 건너뛰기`는 그대로. (`aiStepMs`, `tests/ui-q2-presenter.test.js`)

## 라이브 확인 (390x690 iframe, 일반 게임)
- 카드 1번 누름으로 칸 채움, 지역 카드는 칩 8개가 가로 스크롤 없이 화면 안에 모두 보임(칩 누르면 칸 채움).
- 세력 줄: 모바일에서 합계만, 탭하면 "지역 0 · 위신 2 · 합계 2".
- 계획 확정 후 지역 질문 없이 해결됨. `해결 시작`부터 정비 요약까지 4.4초(내 카드 2장 포함).
- 지도 라벨 상자끼리 겹침 0, 확대 버튼과 겹침 0, 지도 밖으로 나감 0 (390, 1280).

## 남은 문제
- 지역 필요 카드 중 지역 두 곳(`regionPair`)이나 대상 세력을 고르는 카드는 예전처럼 해결 때 묻는다.
- 라벨 겹침은 상자 좌표로 검사했고 눈으로는 북미 라벨만 확인함(남미 라벨은 독에 가려 보지 못함).
- 계획 후 새로고침하면 미리 고른 지역이 사라져 해결 때 다시 묻는다.
