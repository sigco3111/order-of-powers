### 가공 내역
- 파일명은 소문자·스네이크 케이스로 정리했습니다(Kenney UI Pack, Board Game Icons 등). 내용은 원본 그대로입니다.
- WAV/MP3 3개(승리 효과음, 패배 효과음, Contemplation)는 용량과 웹 재생을 위해 OGG로 변환했습니다.
- 3D 팩(`assets-3d-lowpoly`)은 2D 카드/보드 게임에 맞지 않아 가져오지 않았습니다.
- 제외: Kenney Music Jingles(곡 성격을 확인하지 못해 보류), Kenney Impact Sounds, Board Game Info(인원·연령 안내용 아이콘), Flag Pack(세계 지도/국기는 사용하지 않음), Generic Items(도구·가전 아이콘).
- 배경음은 직접 들어보지 않고 곡명·태그(calm/ambient 계열)로 골랐습니다. 적용 전에 청취 확인이 필요합니다.
