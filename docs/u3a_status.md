# U3a 상태: 카드 플레이 화면

## 점검 결과 (기준 0ee7e3d)
- 부품(카드·효과 문구·손패 트레이·선택 패널·공개/해결 연출·이벤트/정산 시트)은 있었지만 `screen-game.js`에 연결돼 있지 않았다.
- 화면은 "자동 계획(임시)" 버튼으로만 진행됐고, `play.css`도 `index.html`에 링크되지 않았다.
- 사건 카드 문구 중복, 기록 줄의 지역 id·"위신 위신", 정산 표 테두리, "(을)를" 같은 표시 오류가 있었다.

## 지금 되는 것 (라이브 확인)
- 한국으로 새 게임 → 전략 자산 고르기 → 사건 카드 → 손패에서 카드 상세 → 계획 칸에 넣기/순서 바꾸기/건너뛰기 확정.
- 계획 확정 → 공개 → 해결 연출(단계별 지도 변화) → 지역 선택이 필요하면 지도에서 직접 고르기(`방어`, 영향력 등) → 정산 시트 → 다음 라운드. 라운드 4까지 실제 클릭으로 진행, 콘솔 오류 없음.
- 첫 판 안내 4장(`oop-seen-hints`), 빠른 진행(속도만 바꿈), 연출 건너뛰기.
- 숨김 디버그 버튼은 `?debug=1`일 때만.
- 테스트: `node --test` 107개 중 106 통과, 1 건너뜀. 사람 한 판을 `loop.submit`으로 6/8/10라운드 돌리는 스크립트 테스트 포함.
