# 규칙 결정 사항 (M1a)

엔진 구현 전에 확정한 규칙. 이후 마일스톤은 이 문서를 기준으로 한다.

- **세력**: 4개 고정. 손패 5장, 계획 슬롯 3개 (성장 카드로 증가 가능).
- **시작 자원**: 💰 4, 🛢 2, 🏭 2, ⭐ 0. 구매 비용은 **자본으로만** 지불한다.
- **수입(정비 단계)**: 💰 +2, 그리고 주도하는 지역마다 그 지역 산출 자원 +1.
- **영향력**: 세력당 한 지역 최대 6. 지역 전체 토큰 수는 제한 없음 (세력별 6 이하).
- **지역 주도**: 영향력 최다 세력. 동률은 서로 모두 조약 상대일 때만 공동 주도(각자 전액), 아니면 아무도 없음. 영향력 0은 주도 불가.
- **지역 점수**: 주도 세력이 `scoreValue(+scoreBonus)`를 **매 라운드** 누적 점수에 더한다.
- **최종 점수**: 누적 지역 점수 + 위신 + 비밀 목표 점수. 동점은 위신 → 자본 순.
- **해결 순서**: 라운드마다 회전. 시작 인덱스 = (round−1) mod 4.
- **이벤트**: 라운드마다 1장. 게임 시작 때 라운드 수 크기의 이벤트 덱을 만든다 (일반 이벤트 무작위 + 이벤트 20은 항상 `rounds−1` 라운드에만).
- **시작 덱**: `factions.json`의 startingDeck 12장. 튜토리얼이면 공용 시작 덱 10장(`tutorialCount`).
- **드로우**: 계획 단계 시작에 손패 한도까지 뽑는다 (생성 시점엔 뽑지 않음). 덱이 비면 버린 더미를 섞어 보충.
- **시장**: 공개 6칸, 시장 카드 45장을 섞은 덱에서 보충. 세력 고유 카드 8장과 중립 카드 2장은 공용 시장에 넣지 않는다.
- **첫 구매 슬롯**: 세력마다 고유 카드 2장이 개인 슬롯에 있고 그 세력만 구매할 수 있다. 구매 시 버린 더미로 가며 시장은 보충하지 않는다.
- **구매**: 구매 카드는 구매자의 버린 더미로. 성장 카드(10종, 세력당 1회)는 `growth`에 두고 덱에 넣지 않으며 수정치를 즉시 적용.
- **비용 수정치**: `shop.costDelta` 합산, 첫 구매는 `shop.firstPurchaseDiscount` 추가 할인, 최소 비용 1. `shop.extraSlots`는 시장 칸 수 증가.
- **전략 자산**: 세력마다 2장을 받아 1장 선택. **비밀 목표**: 세력마다 2장.

## 효과 실행기 (M1b)
- **수정치 키**: `income.<capital|energy|industry|prestige>`, `shop.costDelta/extraSlots/firstPurchaseDiscount/minCost`, `planSlots`, `handSize`, `nextRound.<key>`(다음 라운드로 승계), `influenceLossReduction.all|self`, `negateTargetedEffect`, `ignoreEventEffectInRegion`(+`PerRound`), `domesticCapitalBonus`, `militaryEffectHalfRoundUp`, `treatiesVoid`, `baseDefenseBonus`, `firstDiplomaticInfluenceBonus`, `firstTreatyFree`(조약 비용이 없어 저장만), `revealPlanCard`. 불리언은 1로 저장. 읽기는 `getMod`/`getModifier`(세력 영구 + 세력 라운드 + 게임 + 전역 라운드 합).
- **저장 위치**: 이벤트와 `.all` 키는 `state.modifiers.round/game`, 카드의 `round`는 `players[f].roundModifiers`, `game`은 `players[f].modifiers`. `clearRoundEffects`가 방어·라운드 수정치·조약·`peeked`를 비우고 `nextRound.*`를 승계.
- **방어**: 방어 1점이 영향력 −1을 막고 소모된다. 감소 수정치 → 방어 흡수 → 제거 순. `evt-18`의 "방어 없음"은 세력별(그 세력 방어 0).
- **제거 대상**: `other`는 상대가 둘 이상이면 대상 세력 선택. `leader`·`evt-06`은 최다 동률 전원. `mil-12`의 −1은 대상 세력의 기지가 있을 때.
- **대기 선택 `state.pending[]`**: `{id, faction(선택자), kind, effect, options, filter, actor, stage, rest, ctx}`. `kind`별 선택값: `region`=지역 id, `faction`=세력 id, `card`=카드 id, `regionPair`=서로 다른 지역 id 2개 배열, `confirm`=true/false(`payOptional`). 선택지가 하나뿐이면 대기 없이 진행. `rest`는 남은 효과 대기열.
- **이벤트 조건**: 시작 시점 스냅샷으로 세력별 판정, 동률은 모두 해당. `playedCategoryThisRound`·`cardsPlayedThisRoundRank` 이벤트는 해결 단계 뒤에 적용해야 하므로 `isDeferredEvent`로 구분.

## 라운드 리듀서 (M1c)
- **API**: `reduce(state, action, data?)` → `{ok, state, events, reason?}` (순수, 실패 시 원본 상태 그대로 + 한국어 `reason`). `data`를 생략하면 `createGame`/`setData`로 등록한 것을 쓴다. `config.debug`이면 성공할 때마다 `validateInvariants`를 실행한다 (실패 시 throw).
- **단계**: `setup`(전략 자산 선택) → 라운드마다 `event → plan → reveal → resolve → upkeep → shop` → `end`. 입력이 필요한 곳(계획·선택 대기·상점)까지 `advance`가 자동 진행한다. 선택 대기(`state.pending`)가 있으면 `CHOOSE`만 받는다. 선택자는 `pending[0].faction`.
- **계획**: `PLAN {cards}`는 손패에서 슬롯 수 이하(순서가 해결 순서). 빈 계획과 `SKIP_PLAN`은 같다. 제출 뒤 수정 불가. `USE_ASSET`은 계획 단계에서 제출 전에만(1회), `PLAN.assetUse`는 제출 직후 사용 (슬롯 +1 자산은 `USE_ASSET`을 먼저). `USE_ASSET.target`은 첫 선택 대기에 미리 답한다.
- **해결**: 세력 순서대로 계획 카드를 앞에서부터 한 장씩. 해결 중 손패 버림 등으로 사라진 계획 카드는 건너뛴다. 지연 이벤트(`isDeferredEvent`)는 이벤트 단계에서 공개만 하고 해결 단계 뒤 적용.
- **정비**: 지역 정산 → 수입(💰 +2, 주도 지역 산출 +1, `income.*` 수정치 합; 자원 수입은 0 미만이 되지 않음, 위신 수입은 수정치 그대로) → 사용 더미를 버린 더미로 → 시장 보충. 안 낸 손패는 유지된다.
- **라운드 정리 시점**: 이벤트의 `shop.*` 수정치가 같은 라운드 상점에 적용되도록 `clearRoundEffects`는 **상점이 끝난 뒤** (다음 라운드로 넘어갈 때) 실행한다. 마지막 라운드는 정비 뒤 바로 최종 점수 (조약·방어는 정리 전 상태로 계산).
- **상점**: 세력마다 `BUY`를 여러 번, `END_SHOP`으로 종료. 세력 간 순서 없음. 구매 시 시장 즉시 보충.
- **종료**: `state.result = {winner, winners, tie, ranking, scores}`. 순위는 총점 → 위신 → 자본, 그래도 같으면 공동 승리(`tie: true`, `winner`는 순위 첫 세력).
- **합법 수**: PLAN은 순서가 있는 카드열을 모두 열거하고 200개를 넘으면 시드 RNG(`state.rng`+세력+라운드)로 표본 추출 (빈 계획 항상 포함). 같은 상태면 같은 표본.
- **owned 필터 수정 (퍼즈에서 발견)**: 한 카드에 지역 효과가 둘 이상이고 그중 `filter: owned`가 있으면(징집령) 첫 지역 선택부터 내 영향력이 있는 지역으로 좁힌다. 내 영향력이 있는 지역이 없으면 방어 등은 아무 지역에나 두되 `owned` 영향력은 생략한다. (수정 전에는 징집령이 빈 지역에 영향력을 만들어 `polarStar`가 무작위 플레이의 80% 이상을 이겼다.)
## AI와 시뮬레이터 (M1d)
- **마지막 라운드는 상점을 건너뛴다**: 정비(정산·수입) 뒤 바로 최종 점수. 마지막이 아닌 라운드의 상점은 그대로. (M1c의 "마지막 라운드도 상점까지 진행"을 대체)
- **완전 동점은 공동 승리**: 총점 → 위신 → 자본까지 같으면 `result.tie = true`, `winners`에 모두 담는다 (시뮬레이터는 분수 승리로 센다).
- 나머지 규칙은 변경 없음. AI는 `src/ai/ai.js`, 시뮬레이터는 `tools/simulate.js`.
- **AI 설계** (`src/ai/ai.js`): `chooseAction(state, faction, {level, rngSeed})`는 `legalActions` 중 하나를 돌려주고 입력 상태를 바꾸지 않는다 (시뮬레이션은 복제본, 시드는 rngSeed + 상태 해시). 계획은 후보(최대 60개 표본 → 상위 N개)를 복제본에서 정비 단계까지 돌려 `evaluate`로 비교한다. 상대의 손패·제출된 계획은 보지 않고, 카드 컬렉션에서 가치로 가중한 계획을 표본(보통 1개, 어려움 3개)으로 가정한다. 해결 단계의 선택은 공개 정보이므로 실제 계획으로 시뮬레이션한다.
- **`evaluate` 가중치**: 누적 점수 + 지역 기대 점수(주도·격차·1~2 차이 접전 × 남은 정산 수) + 영향력·기지 + 자본(남은 상점 수에 비례, 마지막 라운드 0) + 비밀 목표 진행(보통 0.5, 어려움 1.0) + 손패 − 상대 감점(전체·최강·점수 선두). 어려움은 마지막 2라운드에 미래 할인 없이 계산한다.
- **시뮬레이터**: `node tools/simulate.js --games N --rounds 6|8|10 --levels a,b,c,d --seed S [--rotate-seats] [--json out.json]`. `--rotate-seats`는 난이도 배정과 좌석(해결 순서) 순서를 판마다 섞는다. 공동 승리는 승률에 분수로 센다.
- **조정 전 기준 승률** (보통 4명, 라운드별 300판 (10라운드는 시드 1·2 각 150판), 외교형/산업형/군사형/성장형): 6라운드 25/23/23/29%, 8라운드 31/23/22/24%, 10라운드 38/21/25/17%. 밸런스 조정(M1e)의 출발점이며 이 마일스톤에서는 규칙을 바꾸지 않았다.
- **강도(참고)**: 어려움 1 대 쉬움 3에서 어려움 승률 약 60% (기대값 25%). 어려움 대 보통은 100판 안팎의 표본에서 차이가 오차 범위 이내 (둘 다 약 25%) — 평가 함수 개선은 다음 과제.

## M1f: 점수 쏠림과 영향력 소멸
진단(`node tools/diagnose.js`): 보통 AI 4명 8라운드에서 1위 53점 / 4위 8점, 3라운드 선두가 85% 우승, 지도의 영향력은 라운드마다 약 1개씩만 늘어 끝에 13개. 원인은 제거가 아니라 **영향력 유입 부족**이었다 (카드 제거 ≈0, 이벤트 제거 0.3~0.4개/라운드). 시작 덱의 영향력 카드(외교 서한·금융 지원·수출 촉진·징집령)가 모두 "이미 내 영향력이 있는 지역"만 허용해, 영향력이 0인 세력은 시장 카드를 사기 전까지 첫 영향력을 놓을 수 없었고 먼저 놓은 세력만 복리로 늘었다.
- **외교 서한: 아무 지역** (`owned` → `any`). 금융 지원·수출 촉진·징집령은 `owned` 유지. 시작 덱 외교 서한 수를 2~3장으로 맞췄다 (산업형 3→2, 군사형 1→2, 성장형 4→3, 자세한 덱은 `docs/CARDS_EXPANSION.md`).
- **지역 점수 가치 절반**: scoreValue 3→1, 4→2, 5→3 (합계 32 → 16 / 라운드). 매 라운드 정산은 그대로. 영향력이 늘면서 주도 지역이 많아져 점수가 2배가 되는 것을 막는다. AI 평가가 같은 `scoreValue`를 쓰므로 AI와 일관된다.
- **추격 보너스(새 규칙)**: 라운드 시작(이벤트 직후, 손패 뽑기 전)에 누적 점수(지역+위신)가 가장 낮은 세력(동률은 모두; 1라운드·전원 동점이면 없음)은 💰 +1, 그 라운드 첫 영향력 배치 +1. 구현: `score.js applyCatchUp`, 효과는 `effects.js`의 `influence`에서 `player.catchUp`을 소모.
- **카드 수치**: 산업형 일대 인프라 비용 3→5, 성장형 공동 규범 비용 3→2, 외교형 해양 동맹 비용 4→3, 시작 덱 재배분 (승률 보정, `docs/CARDS.md`).
- **제거 약화는 하지 않았다**: 제거 카드·이벤트는 1~2 수준이고 방어가 흡수한다. 라운드당 소멸은 평균 10% 미만이라 그대로 둔다.
- 규칙 화면(`src/ui/play.js` 첫 판 안내)에 추격 보너스 메모를 추가했다.
- **진단 훅**: `effects.js`가 `globalThis.__diag`가 있을 때만 영향력 증감을 알린다 (`tools/diagnose.js` 전용, 평소엔 무시).
## M2 (AI와 밸런스)
- 비밀 목표 수치 완화 (AI가 한 판에 거의 못 채우던 항목): 세 대륙의 기지 → **두 대륙의 기지**(기지 3→2개 지역), 조약의 달인 3→2번, 영향력 포식자 8→4, 패권의 증거 4→3곳, 막판 역전 4→3, 외교의 달인 15→12장, 군사 대국 15→10장, 존경받는 강국 위신 12→10, 마지막 승부 5→4곳. 점수는 그대로. 규칙서(src/ui/rules.js 예시 문장, docs/RULES.md)와 docs/CARDS_EXPANSION.md 표에 반영.
- 규칙 문구와 카드·지도·시작 덱 수치는 바꾸지 않았다.
- 측정 수치, 전/후 표, 남은 문제는 [BALANCE_REPORT.md](BALANCE_REPORT.md) 8장 (M2).
